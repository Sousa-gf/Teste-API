# Dois anos de nós — versão 2.0 ♡

Versão redesenhada com foco principal em celulares.

### Novidades
- Tela de abertura antes da história.
- Layout pensado mobile-first.
- Navegação fixa por capítulos.
- Carrossel horizontal com toque/swipe.
- Barra de progresso das memórias.
- Cartas que viram com toque.
- Timeline expansível otimizada para toque.
- Seção final ocupando a tela inteira.
- Respeita `prefers-reduced-motion`.
- Continua responsivo para tablets e desktop.

Abra `index.html` para visualizar.

Para colocar fotos reais, crie uma pasta `img/` e substitua os blocos `FOTO`/placeholders por `<img>` no HTML.
